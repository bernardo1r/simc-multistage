# simc-multistage
[simulationcraft](https://github.com/simulationcraft/simc) wrapper to allow simming several combinations in a sensible amount of time.

It does this by allowing the target margin of error to be set for each stage and discarding the outliers along the way.

⚠️ **THIS PROJECT IS IN A VERY EARLY STAGE. USE WITH CAUTION!**

Currently, it exists only as a functional minimum viable product in the `mvp` branch.
